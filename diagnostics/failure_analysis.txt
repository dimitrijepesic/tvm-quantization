Sub-byte quantization failure analysis
=======================================

Each bitwidth fails at a different stage of the TVM pipeline, which reveals
that there is no unified validation layer — each pass imposes its own
dtype-specific assumptions independently.


int4 native — relay.build() does not terminate
----------------------------------------------
Symptom: relay.build() runs CPU-bound at ~100% on a single core for
29+ minutes with no progress, no exception, no assertion. We terminated
the process externally with SIGTERM (timeout); no clean error site was
ever reached.

Python stack (sampled every 30 s via faulthandler.dump_traceback_later)
is stable throughout — Python is parked in a single FFI call:
  python/tvm/relay/build_module.py:161, BuildModule.build (= self._mod["build"])
  -> python/tvm/_ffi/_ctypes/packed_func.py:229, __call__
  -> python/tvm/_ffi/_ctypes/packed_func.py:86, cfun
The hang is therefore on the C++ side, inside libtvm.so, with no Python
loop and no progress signal. ps shows ~105% CPU and stable ~1.2 GB RSS,
so the process is computing, not blocked on I/O.

quantize.quantize() succeeds and produces valid Relay IR with int4 dtypes
(461 occurrences of "int4" in the IR text; 53 nn.conv2d, 222 cast,
122 clip, 82 right_shift, 56 multiply ops post-realize).

Note: the architectural reason sub-byte dtypes cannot pass LLVM codegen is
the assertion ICHECK_GE(value_dtype.bits(), 8) at
src/target/llvm/codegen_llvm.cc:1716 (CodeGenLLVM::BufferAccessHelper) —
that check exists in the source. In this run, the build does not reach
that check; it stalls in an earlier pass.


int2 native — clean InternalError during quantize.quantize()
------------------------------------------------------------
Location: src/tir/transforms/arg_binder.cc:277, ArgBinder::BindDLTensor
          -> include/tvm/runtime/data_type.h:256, GetVectorBytes

Error:
  Check failed: data_bits % 8 == 0U (2 vs. 0):
  Need to load/store by multiple of bytes

Surface: quantize.quantize() itself, during the prerequisite_optimize
step (python/tvm/relay/quantize/quantize.py:329). That helper
transparently invokes a downstream build of intermediate IR (via
Interpreter::TIRToPackedFunc and driver.build) in order to JIT-compile and
execute small subgraphs for calibration. The int2 storage dtype then flows
into TIR transforms (MakePackedAPI), where ArgBinder::BindDLTensor calls
GetVectorBytes(int2) — and GetVectorBytes (data_type.h:252-256) has an
explicit whitelist for Bool, Int(4), UInt(4), Int(1) (which return 1 byte)
but NOT Int(2), so the ICHECK_EQ(data_bits % 8, 0U) fires.

The error is a clean InternalError exception, not a segfault. Stack:
  quantize.quantize
  -> prerequisite_optimize (quantize.py:329)
  -> Interpreter::TIRToPackedFunc
  -> driver.build
  -> MakePackedAPI (make_packed_api.cc:335)
  -> ArgBinder::BindDLTensor (arg_binder.cc:277)
  -> GetVectorBytes (data_type.h:256)
  -> ICHECK_EQ(data_bits % 8, 0U) failure

Implication: the failure surface for int2 is not the Relay quantization
pipeline but the TIR-level buffer-binding pass — and TIR's storage model
assumes byte-multiples, while Relay's quantization does not validate that.


int1 native — fails at relay.build(), SimplifyExpr optimization pass
--------------------------------------------------------------------
Location: src/relay/transforms/simplify_expr.cc:170, CheckDataTypeMaxMinValue()

Full error path:
  relay.build()
  -> src/relay/backend/build_module.cc:356, OptimizeImpl()
  -> src/relay/transforms/simplify_expr.cc:1145, SimplifyExpr()
  -> src/relay/transforms/simplify_expr.cc:221, SimplifyClipAndConsecutiveCast::Callback()
  -> src/relay/transforms/simplify_expr.cc:170, CheckDataTypeMaxMinValue()
  -> src/tir/op/op.cc:259, tvm::min_value(DataType::Int(1))
  -> src/ir/expr.cc:84, IntImm(int1, -1) constructor

The SimplifyExpr pass tries to validate clip op bounds by computing
min_value(int1). TVM treats DataType::Int(1) as effectively boolean with
range [0, 1]. Constructing IntImm(int1, -1) for the clip's lower bound
triggers the assertion:

  Check failed: (value == 0 || value == 1) is false:
  ValueError: -1 exceeds range of int1

quantize.quantize() succeeds (IR contains 461 "int1" substrings), but
relay.build() fails with a clean InternalError exception.
